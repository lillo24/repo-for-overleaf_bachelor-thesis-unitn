\section{Quantitative Results}
The final quantitative analysis is reported through one consolidated table covering the original-query baselines and the three frozen rewrite sets on both the polished and noisy corpora. The table reports strict and lenient Hit@1, Hit@3, and MRR, together with the extra-context metrics defined in Chapter~4.

The consolidated presentation is preferred over separate partially overlapping tables because it supports three comparisons at once:

\begin{itemize}
    \item the effect of query rewriting relative to the original-query baseline;
    \item the stability of the three independently generated rewrite sets;
    \item the effect of corpus noise when the same frozen rewrites are applied to both source sets.
\end{itemize}

The numerical table is maintained as the single source of truth for the final results and is intentionally not duplicated elsewhere in this chapter.

\section{How the Results Should Be Read}
Hit@3 is the main answerability measure: it captures whether at least one useful official source appears in the retrieved window. Hit@1 and MRR describe ranking quality within that window. Strict metrics require a directly relevant source, while lenient metrics also accept partially useful evidence.

The extra-context metrics answer a different question. They measure whether an already answerable query receives additional useful sources after the primary hit has been removed. They should therefore be interpreted as evidence richness, not as a replacement for Hit@3.

The repeated rewrite runs are evidence of directional robustness rather than perfect determinism. With 26 cases, one changed case corresponds to approximately 3.8 percentage points, so small metric changes may reflect only one query moving between ranks.

\section{Discussion and Error Analysis}
The evaluation distinguishes failures caused by query formulation from failures caused by the retrieval environment.

\begin{itemize}
    \item \textbf{Lexical mismatch}: the student wording and official terminology remain too different;
    \item \textbf{Rewrite drift}: augmentation introduces a neighbouring administrative intent or unsupported assumption;
    \item \textbf{Generic-language collision}: common conversational expressions match unrelated FAQ headings;
    \item \textbf{Missing source}: the correct official document is absent from the selected corpus;
    \item \textbf{Corpus noise}: additional unrelated documents compete with the intended source;
    \item \textbf{Granularity or field-weighting issue}: the right document is indexed, but its relevant segment is not competitive;
    \item \textbf{Duplicate or yearly versions}: similar documents compete for the same ranking positions.
\end{itemize}

The polished/noisy comparison is particularly important because it tests whether rewriting remains useful when relevant sources must compete with a substantially larger corpus. A rewrite that performs well only in the curated corpus would be less convincing as a practical retrieval component.

\section{Product Context}
The thesis is extracted from a broader prototype for a university bureaucracy assistant. The complete system includes controlled acquisition, manifest and revision tracking, HTML/PDF extraction, OpenSearch BM25 retrieval, backend APIs, a frontend interface, and debugging tools.

The thesis isolates retrieval because correct source selection is a necessary condition for grounded answer generation. Fluent generation cannot compensate for missing or irrelevant evidence.

\section{Limitations}
The benchmark contains 26 queries, so the results should not be interpreted as a comprehensive estimate for all university bureaucracy questions. The cases are manually curated and judged by one evaluator, which introduces possible selection and annotation bias.

The experiment evaluates only the top three distinct documents. It does not measure full answer correctness, citation faithfulness, refusal quality, latency, or student satisfaction. The corpus is also limited to selected institutional domains and one university context.

Query rewriting may improve lexical matching while still changing the user's intent. Manual relevance judgement and qualitative inspection remain necessary even when aggregate metrics improve.

\section{Conclusions}
This thesis evaluates a low-cost LLM as a thin semantic layer over deterministic BM25 retrieval. The model does not replace the search engine and is not evaluated as the final answer generator. Its role is to preserve the student's information need while adding a small amount of institutional vocabulary that can make the intended official source more competitive.

The central contribution is therefore both architectural and empirical: a reproducible retrieval pipeline, a controlled original-versus-rewritten benchmark, and an analysis of how rewrite variability and corpus noise affect the result.

\section{Future Work}
Future work may include:

\begin{itemize}
    \item an Italian stemmed or analysed fallback field while retaining exact-field boosts;
    \item hybrid lexical and vector retrieval;
    \item reranking of the BM25 candidate set;
    \item larger and independently judged evaluation datasets;
    \item automatic checks for rewrite drift;
    \item broader source coverage and stronger yearly-document handling;
    \item full assistant evaluation, including answer correctness, citations, refusals, and user studies.
\end{itemize}
